# 장바구니에서 품의까지

쇼핑몰 장바구니를 품목내역 엑셀로 정리하는 **품의담기**와, 결과 파일을 K-에듀파인 품의등록 화면에 반영하는 **품의올리기** 스킬입니다. 스킬은 AI에게 작업 순서를 알려 주는 파일입니다.

## 준비물

- Windows PC, Microsoft Excel, Codex 사용 환경
- 로그인된 쇼핑몰 및 K-에듀파인과 해당 업무 권한
- Codex가 로그인된 브라우저를 읽고 조작할 수 있는 환경
- 인터넷 연결 및 품의를 진행할 예산 정보

환경과 사이트 화면에 따라 추가 설정이 필요할 수 있습니다. 이 배포본은 다른 PC에서 아직 처음부터 끝까지 검증하지 않았습니다.

## 설치하기: GitHub를 처음 쓴다면

1. 이 저장소의 GitHub 페이지에서 초록색 **Code → Download ZIP**을 누릅니다.
2. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**를 선택합니다.
3. 압축을 푼 폴더에서 `skills` 폴더를 열고, `pumui-damgi`와 `pumui-olligi` 폴더 두 개를 복사합니다.
4. 파일 탐색기 주소창에 `%USERPROFILE%\.agents\skills`를 입력합니다. 폴더가 없으면 직접 만듭니다.
5. 그곳에 두 폴더를 그대로 붙여넣습니다. 각 폴더 안에 `SKILL.md`가 바로 보여야 합니다.
6. Codex를 다시 시작하거나 새 세션을 열고 “설치된 품의담기와 품의올리기 스킬을 확인해 줘”라고 요청합니다.

서식 파일과 배송비 집계용 Python 파일도 폴더 안에 들어 있습니다. **`SKILL.md`만 복사하지 말고 두 스킬 폴더를 통째로 복사하세요.** Python 파일은 배송비 집계 보조 기능이며 이를 실행하려면 Python이 필요합니다. 실행이 불가능하면 AI가 같은 규칙으로 집계하고 결과를 검증해야 합니다.

## 사용하기

1. 쇼핑몰에 로그인하고 장바구니에서 품의할 상품을 선택합니다.
2. Codex에 “품의담기 스킬로 선택한 장바구니 상품을 엑셀로 만들어 줘”라고 요청합니다. 기본 서식은 동봉되어 있으며 원본을 보존한 결과 사본을 만듭니다.
3. 결과를 확인한 뒤 K-에듀파인에 로그인합니다. Codex에 예산과 제목을 알려 주고 “품의올리기 스킬로 이 엑셀을 반영해 줘”라고 요청합니다.
4. 기본 완료 지점은 개요·예산·품목을 화면에 반영한 상태입니다. **저장과 결재요청은 별도로 지시해야 합니다.**

장바구니 가격, 배송비, 예산과 합계는 결과 화면에서 확인하세요. 구매와 결제는 수행하지 않습니다.

## 다른 PC로 옮기기

GitHub를 다시 이용하지 않아도 됩니다. `skills` 폴더 안의 `pumui-damgi`와 `pumui-olligi` 폴더를 통째로 USB나 안전한 파일 공유 방법으로 옮기고, 위 설치 절차 4~6번을 진행하세요. 개인 계정·장바구니·업무 권한은 함께 옮겨지지 않습니다.

## 폴더 구성

```text
skills/
├─ pumui-damgi/
│  ├─ SKILL.md
│  ├─ assets/품목내역(통합).xls
│  └─ scripts/group_shipping.py
└─ pumui-olligi/
   └─ SKILL.md
```

동봉한 엑셀은 빈 서식입니다. 사용자가 다른 서식을 지정하면 그 서식을 우선합니다. 사이트 접근 및 Excel 조작은 스킬 자체가 아니라 실행 환경의 도구와 권한에 의존합니다. Antigravity 등 다른 환경에서의 사용은 별도 검증이 필요합니다.
